# Martin Gachucha Portfolio (Next.js + TypeScript + Tailwind)

    npm install
    npm run dev          # local preview
    npm run typecheck    # strict TypeScript check
    npm run build        # production build

Deploy: push to GitHub, then import the repo in Vercel (no settings needed).

Edit content in `data/site.ts`: contact details, funnel stages, skills, experience, image paths.
Add your resume at `public/resume.pdf` and images in `public/images`.
Phone and LinkedIn stay hidden until you replace the `[ADD ...]` values in `data/site.ts`.
